01

Start with the audience

The same detail can be useful in a private handoff and inappropriate in a team story.

Uses your existing Azure CLI sign-in. Team membership does not mean every session detail should be shared.

Always protected: recognized credentials, hidden reasoning and binary payloads are excluded before review. Detection is not a guarantee of anonymity. Technical failures, corrections and acceptance limits are useful history—not something to hide by default.
02

Make the story yours to share

No one else gets to decide what feels uncomfortable to you. These are suggestions, not judgments.

Remove replaces a selected span, not a whole turn. Pseudonyms preserve links, not anonymity. Personal or contextual findings always need your individual choice—even when a model calls them unnecessary. Conflicting keep/removal choices block generation. Expand each finding to inspect the surrounding text and related clues.

Generation sends the approved reduced session to your authenticated Copilot and uses your Copilot quota. “Local only” means no ArtifactStore upload, not on-device model generation. A joint draft stays in the private workspace; only my selected reader files are delivered.

03

Read it before it leaves

Human: HTML story. Agent: Markdown only. Evidence: a separate, optional reference.

If your embedded browser blocks downloads, open the existing files locally. This uses your default file app, not an Agent HTML viewer.

Preview the human story
Check the problem, failed and successful paths, uncertainty, first useful action and acceptance. Privacy reduction must not turn a failed attempt into a success story. Read both Markdown files in your editor.
04

A deliberate last check

Only the final documents travel. Never the transcript, reversal map, private review or model cache.
